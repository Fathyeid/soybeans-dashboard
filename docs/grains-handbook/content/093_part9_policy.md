# الفصل ث2: نموذج سياسة إدارة المخاطر ونموذج استبيان KYC

هذا الفصل يقدم نصًا نموذجيًا لسياسة إدارة مخاطر لشركة تجارة حبوب متوسطة الحجم، ونموذج استبيان "اعرف عميلك". عدّل النماذج وفق حجم شركتك وقوانين بلدك، واستعن بمستشار قانوني.

## ث2.1 نموذج سياسة إدارة المخاطر

### 1. الغرض والنطاق

تهدف هذه السياسة إلى تحديد إطار تحديد وقياس ومراقبة والتحكم في المخاطر التي تتعرض لها الشركة في أنشطة تجارة الحبوب والبذور الزيتية والزيوت النباتية والأنشطة المرتبطة (الشحن، التمويل، التحوط). تنطبق على جميع الموظفين والمكاتب والشركات التابعة.

### 2. المبادئ

- الشركة تاجر فعلي؛ نشاطها في البورصة **للتحوط** أساسًا، مع هامش محدود للمراكز الاتجاهية ضمن حدود معتمدة.
- كل مخاطرة يجب أن تكون معروفة ومقاسة ومعتمدة ومسعرة.
- الفصل بين المهام (الأمامي/الأوسط/الخلفي) إلزامي.

### 3. الحوكمة

| الجهة | المسؤوليات |
|---|---|
| مجلس الإدارة | اعتماد السياسة، تحديد شهية المخاطر الإجمالية، مراجعة سنوية |
| لجنة المخاطر | اعتماد الحدود التفصيلية، مراجعة شهرية، معالجة التجاوزات |
| الرئيس التنفيذي | تنفيذ السياسة |
| رئيس المخاطر (مستقل عن التداول) | القياس اليومي، التقارير، مراقبة الحدود |
| رؤساء الديسكات | الالتزام بالحدود في ديسكاتهم |
| العمليات والمالية | التسويات، التقييم المستقل، المطابقة مع الوسطاء والبنوك |

### 4. أنواع المخاطر والحدود

| المخاطرة | المقياس | الحد (مثال) |
|---|---|---|
| السعر المطلق | صافي المركز بالطن لكل سلعة | قمح: ±50,000 طن؛ ذرة: ±50,000؛ صويا: ±30,000؛ زيوت: ±10,000 |
| البيسيس | صافي مركز البيسيس | ±150,000 طن لكل منطقة |
| الفروق الزمنية | | حسب الديسك |
| النولون | أيام السفن غير المغطاة | 300 يوم-سفينة |
| القيمة المعرضة للخطر | VaR يومي 95% | 1,000,000 دولار للشركة |
| حد الخسارة | خسارة شهرية تراكمية | 2,000,000 دولار تستوجب مراجعة إلزامية للجنة |
| الطرف المقابل | التعرض لكل طرف حسب تصنيفه | من 1 إلى 20 مليون دولار |
| الدولة | التعرض لكل دولة | حسب تصنيف الدولة |
| المدة | أقصى مدة للتعاقد | 18 شهرًا |
| السيولة | الهوامش المحتملة في سيناريو ضغط | يجب تغطيتها بخطوط مؤكدة |

### 5. الأدوات المسموحة

- العقود الآجلة والخيارات المدرجة في البورصات المعتمدة (CBOT، Euronext، Bursa Malaysia، ICE).
- شراء الخيارات؛ بيع الخيارات مسموح فقط ضمن استراتيجيات مغطاة معتمدة.
- FFA للنولون عبر المقاصة.
- عقود الصرف الآجلة للعملات.
- أي أداة جديدة تتطلب موافقة لجنة المخاطر.

### 6. القياس والتقارير

- **يوميًا:** تقرير المراكز، MTM، الربح والخسارة، استخدام الحدود، VaR.
- **أسبوعيًا:** اختبار الضغط، تقرير التعرض الائتماني.
- **شهريًا:** تقرير للجنة المخاطر.
- **التقييم:** الأسعار المستخدمة في MTM يحددها قسم المخاطر من مصادر مستقلة.

### 7. التجاوزات

- أي تجاوز لحد يُبلغ فورًا لرئيس المخاطر والرئيس التنفيذي.
- خطة تصحيح خلال يوم عمل.
- التجاوزات المتكررة أو غير المبلغ عنها مخالفة تأديبية.

### 8. مخاطر الائتمان

- كل طرف مقابل يمر بـ KYC وتقييم ائتماني قبل أول صفقة.
- الحد الائتماني يشمل: الذمم المفتوحة + مخاطرة الإحلال (فرق السعر المحتمل × الكمية غير المنفذة).
- الأطراف غير المصنفة تتطلب ضمانات (اعتمادات معززة، دفعات مقدمة، تأمين ائتمان).

### 9. المخاطر التشغيلية

- إجراءات مكتوبة للتنفيذ (SOPs).
- مراجعة رباعية للمستندات.
- تحقق هاتفي من أي تغيير في بيانات الدفع.
- إجازة إلزامية سنوية متصلة (أسبوعان) للمتداولين.

### 10. المراجعة

تراجع هذه السياسة سنويًا أو عند أي تغيير جوهري في النشاط.

## ث2.2 نموذج استبيان KYC

| القسم | البيانات المطلوبة |
|---|---|
| **أ. بيانات الشركة** | الاسم القانوني الكامل؛ الأسماء التجارية؛ رقم التسجيل وتاريخه؛ بلد التأسيس؛ العنوان المسجل وعنوان النشاط؛ الموقع الإلكتروني؛ الرقم الضريبي |
| **ب. الملكية** | قائمة المساهمين بنسب الملكية؛ المالكون المستفيدون النهائيون (أي شخص يملك أو يتحكم في 10% أو 25% أو أكثر حسب السياسة) مع جنسياتهم وتواريخ ميلادهم ونسخ هوياتهم؛ الهيكل التنظيمي للمجموعة |
| **ج. الإدارة** | المديرون والمفوضون بالتوقيع مع نسخ الهويات |
| **د. النشاط** | وصف النشاط؛ السلع؛ الدول التي يتعامل معها (شراءً وبيعًا)؛ الأحجام السنوية؛ أكبر العملاء والموردين (اختياري) |
| **هـ. المالية** | القوائم المالية المدققة لآخر سنتين؛ البنوك الرئيسية؛ المراجع البنكية |
| **و. الامتثال** | هل الشركة أو أي من مالكيها أو مديريها خاضع لعقوبات؟ هل أي منهم شخص مكشوف سياسيًا؟ هل للشركة تعاملات مع دول أو مناطق خاضعة لعقوبات شاملة؟ هل لديها سياسة لمكافحة غسل الأموال والفساد؟ أي قضايا جنائية أو تنظيمية؟ |
| **ز. الإقرارات** | إقرار بصحة البيانات والتزام بالإبلاغ عن أي تغيير؛ موافقة على الفحص |
| **ح. التوقيع** | توقيع مفوض مع الختم والتاريخ |

### خطوات المراجعة الداخلية

1) فحص الأسماء (الشركة، المالكون، المديرون) في قوائم العقوبات وPEPs والأخبار السلبية.
2) التحقق من السجل التجاري من المصدر الرسمي إن أمكن.
3) تصنيف المخاطر (منخفض/متوسط/مرتفع).
4) للمرتفع: عناية واجبة معززة (EDD) وموافقة الإدارة العليا.
5) تحديد الحد الائتماني.
6) جدولة المراجعة الدورية.

## ث2.3 أسئلة مراجعة

1) لماذا يجب أن يكون رئيس المخاطر مستقلًا عن التداول؟
2) ما الفرق بين حد المركز وحد الخسارة؟
3) لماذا تُعتبر الإجازة الإلزامية للمتداولين ضابطًا رقابيًا؟
4) ما المعلومات الأساسية في استبيان KYC؟
5) متى تحتاج "عناية واجبة معززة"؟
