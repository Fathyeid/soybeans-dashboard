# الفصل ب10ج: سجل التداول ودراسات سلوكية

## ب10ج.1 لماذا سجل التداول؟

سجل التداول (Trading Journal) هو أهم أداة لتحسين الأداء. بدون سجل، تتذكر الأرباح وتنسى أسباب الخسائر. السجل يكشف أنماط أخطائك ويحول التجربة إلى تعلم.

## ب10ج.2 قالب السجل

| العمود | المحتوى |
|---|---|
| التاريخ والوقت | |
| السوق والعقد | مثل ZCZ7 |
| الاتجاه | شراء/بيع/فرق |
| الحجم | عدد العقود |
| سعر الدخول | |
| سبب الدخول | أساسي/فني/موسمي/تحوط — مكتوب بوضوح |
| وقف الخسارة والهدف | |
| المخاطرة بالدولار ونسبتها من الحساب | |
| الحالة النفسية | هادئ، متحمس، خائف، منتقم... |
| سعر الخروج وتاريخه | |
| سبب الخروج | الهدف، الوقف، تغير السبب، قرار عاطفي |
| الربح/الخسارة | |
| الدرس | ماذا تعلمت؟ |

## ب10ج.3 المراجعة الأسبوعية والشهرية

| المقياس | الحساب |
|---|---|
| نسبة النجاح | الصفقات الرابحة ÷ الإجمالي |
| متوسط الربح ومتوسط الخسارة | |
| نسبة العائد للمخاطرة الفعلية | متوسط الربح ÷ متوسط الخسارة |
| التوقع الرياضي (Expectancy) | (نسبة النجاح × متوسط الربح) − (نسبة الخسارة × متوسط الخسارة) |
| أقصى تراجع (Max Drawdown) | أكبر انخفاض من قمة الحساب |
| الالتزام بالخطة | نسبة الصفقات التي اتبعت القواعد |

?> مثال: 40 صفقة: 16 رابحة بمتوسط 1,500 دولار، و24 خاسرة بمتوسط 600 دولار. التوقع = 0.4 × 1,500 − 0.6 × 600 = 600 − 360 = +240 دولار لكل صفقة. نظام إيجابي رغم أن نسبة النجاح 40% فقط.

## ب10ج.4 دراسات سلوكية قصيرة

### الحالة 1: "سيعود"

متداول اشترى ذرة عند 4.80 مع وقف عند 4.65. عند 4.66 حرك الوقف إلى 4.50 "لأن التقرير القادم صعودي". صدر التقرير هبوطيًا، فهبطت إلى 4.35 بفجوة. الخسارة ثلاثة أضعاف المخطط. **الدرس:** الوقف قرار ما قبل الصفقة؛ تغييره تحت الضغط هو الأمل وليس التحليل.

### الحالة 2: الربح المبكر

متداول دخل فرقًا رابحًا بهدف 20 سنتًا، وأغلقه عند 6 سنتات خوفًا من عودته. تكرر ذلك، فأصبح متوسط ربحه أقل من متوسط خسارته، وخسر رغم نسبة نجاح 60%. **الدرس:** اترك الأرباح تعمل وفق الخطة؛ استخدم الوقف المتحرك بدل الإغلاق العاطفي.

### الحالة 3: المتحوط الذي أصبح مضاربًا

مسؤول تحوط في مطحنة رأى أن السوق "سينخفض"، فلم يجدد تحوط الشراء لشحنات المطحنة القادمة. ارتفع السوق 15%. المطحنة دفعت أكثر بكثير لاحتياجاتها. **الدرس:** قرار عدم التحوط هو مضاربة؛ يجب أن يتخذ ضمن سياسة وحدود معتمدة، لا بقرار فردي.

### الحالة 4: الإفراط بعد سلسلة نجاح

بعد 8 صفقات رابحة متتالية، ضاعف متداول حجمه ثلاث مرات. الصفقة التاسعة خسرت ما يعادل أرباح الثماني مجتمعة. **الدرس:** حجم المركز تحدده القواعد، لا المزاج.

## ب10ج.5 روتين الانضباط

1) خطة يومية مكتوبة قبل الافتتاح.
2) لا صفقة دون سبب مكتوب ووقف وهدف.
3) مراجعة يومية قصيرة للسجل.
4) مراجعة أسبوعية للمقاييس.
5) استراحة إلزامية بعد خسارة يومية تبلغ الحد.
6) مرشد أو زميل يراجع سجلك شهريًا.

## ب10ج.6 أسئلة مراجعة

1) ما الأعمدة الأساسية في سجل التداول؟
2) احسب التوقع لنظام: 50% نجاح، متوسط ربح 800، متوسط خسارة 900.
3) لماذا تحريك الوقف بعيدًا خطأ شائع؟
4) كيف يتحول المتحوط إلى مضارب دون أن يشعر؟
5) صمم روتين انضباط شخصيًا.
