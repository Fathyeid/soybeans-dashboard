# الفصل ظ44: التحكيم عمليًا — الجدول الزمني والتكلفة وإعداد الملف

## ظ44.1 جدول زمني نموذجي لتحكيم جودة (تقريبي)

| المرحلة | التوقيت التقريبي |
|---|---|
| اكتشاف المشكلة وإشعار المطالبة | الأيام الأولى بعد التفريغ |
| بدء التحكيم وتعيين المحكم | ضمن المهلة المحددة في القواعد (قصيرة لنزاعات الجودة) |
| تعيين الطرف الآخر لمحكمه | أيام إلى أسابيع |
| المذكرات (المطالبة، الدفاع، الرد) | 2–4 أشهر |
| صدور الحكم الأول | 3–9 أشهر من البداية |
| الاستئناف (إن وجد) | 6–12 شهرًا إضافية |

## ظ44.2 مكونات التكلفة

| البند | ملاحظات |
|---|---|
| رسوم الجمعية والمحكمين | تتناسب مع التعقيد والمبلغ |
| المحامون (إن وُجدوا) | كثير من نزاعات الحبوب تُدار دون محامين خارجيين أو بمستشارين متخصصين لخفض التكلفة |
| الخبراء والمعاينون | تقارير فنية |
| التحليل الإضافي | |
| الوقت الإداري | |
| الضمانات | قد تطلب الجمعية إيداعات لتغطية الرسوم |

القاعدة العامة: الخاسر يتحمل جزءًا كبيرًا من التكاليف، لكن الاسترداد لا يكون كاملًا دائمًا.

## ظ44.3 إعداد ملف المطالبة

1) **ملخص الوقائع** بتسلسل زمني.
2) **العقد** والملحقات والمراسلات الجوهرية.
3) **الأساس القانوني:** البنود التي أُخل بها.
4) **الأدلة:** الشهادات، تقارير المعاينين، التحاليل، الصور، كشوف الوقائع.
5) **حساب المطالبة** مفصلًا بالأرقام والمراجع.
6) **الرد المتوقع للطرف الآخر** والتعليق عليه مسبقًا.

> اكتب المذكرة لقارئ خبير مشغول: واضحة، مختصرة، مرقمة، مع إحالة لكل مستند. المحكمون في الحبوب تجار، يقدرون الدقة والوضوح أكثر من البلاغة.

## ظ44.4 أسئلة مراجعة

1) ما المراحل الرئيسية للتحكيم وتوقيتها التقريبي؟
2) لماذا تُدار كثير من نزاعات الحبوب دون محامين خارجيين؟
3) ما مكونات ملف المطالبة؟
4) من يتحمل تكاليف التحكيم عادةً؟
5) كيف تكتب مذكرة فعالة لمحكمين تجار؟
