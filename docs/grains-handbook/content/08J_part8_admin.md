# الفصل ظ34: إدارة العقود والفواتير والتسويات المحاسبية

## ظ34.1 دورة المستندات المالية للصفقة

| المستند | متى | المحتوى |
|---|---|---|
| الفاتورة المبدئية (Proforma Invoice) | قبل الشحن (لفتح الاعتماد أو التسجيل المسبق) | الكمية والسعر التقديري |
| الفاتورة المؤقتة (Provisional Invoice) | عند الشحن | كمية البوليصة، السعر المؤقت أو النهائي، نسبة الدفع |
| إشعار مدين (Debit Note) | عند استحقاق مبالغ إضافية للبائع | غرامة تأخير، فرق سعر، تكاليف |
| إشعار دائن (Credit Note) | عند استحقاق مبالغ للمشتري | خصم جودة، مكافأة سرعة، نقص كمية |
| الفاتورة النهائية (Final Invoice) | بعد التسوية | كل البنود والرصيد |
| كشف الحساب (Statement of Account) | دوريًا | الأرصدة المفتوحة مع كل طرف |

## ظ34.2 مثال: الحساب النهائي لصفقة

| البند | مدين (للبائع) | دائن (للمشتري) |
|---|---|---|
| قيمة 33,120 طن × 245 دولار | 8,114,400 | |

| المدفوع تحت الاعتماد (98%) | | 7,952,112 |
| **الرصيد المستحق للبائع** | **169,445** | |

## ظ34.3 ضوابط إدارة العقود

1) **سجل العقود** بكل التعديلات (Addenda) مؤرخة وموقعة.
2) **مطابقة الفواتير بالعقود والشهادات** قبل الإصدار.
3) **متابعة الأرصدة المفتوحة** والمطالبة بها في مواعيدها.
4) **تسوية الحسابات مع الأطراف** (Reconciliation) دوريًا.
5) **أرشفة كاملة** لمدة لا تقل عن المطلوب قانونيًا وضريبيًا.

## ظ34.4 الضرائب على الفواتير الدولية

- ضريبة القيمة المضافة عادةً صفرية أو معفاة على الصادرات، لكن قواعدها تختلف حسب البلد ومكان التسليم.
- ضرائب الاستقطاع على العمولات المدفوعة لوسطاء في دول أخرى قد تنطبق.
- التسعير التحويلي بين الشركات الشقيقة يجب أن يكون على أسس تجارية بحتة وموثقًا.

## ظ34.5 أسئلة مراجعة

1) ما الفرق بين الإشعار المدين والدائن؟
2) احسب الرصيد في المثال إذا كان خصم الجودة 0.5%.
3) لماذا يجب مطابقة الحسابات دوريًا مع الأطراف؟
4) ما المستندات المالية المطلوبة في كل مرحلة من الصفقة؟
5) ما المخاطر الضريبية في العمولات الدولية؟
