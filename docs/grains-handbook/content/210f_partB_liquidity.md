# الفصل ب11د: خطة السيولة لتمويل الهوامش — قالب عملي

## ب11د.1 لماذا خطة مكتوبة؟

التحوط الصحيح اقتصاديًا قد يطلب نقدًا كبيرًا في أيام: إذا ارتفعت الأسعار 15% والشركة متحوطة ببيع عقود على مخزون كبير، ستُطلب هوامش ضخمة فورًا بينما الأرباح الفعلية على المخزون لن تتحقق إلا عند البيع. خطة السيولة تحدد مسبقًا من أين يأتي النقد.

## ب11د.2 القالب

| البند | القيمة/الإجراء |
|---|---|
| المراكز المتحوطة الحالية (عقود ونوعها) | |
| الهامش المبدئي الحالي | |
| سيناريو ضغط: حركة سعرية معاكسة (مثلًا 10% و20% و30%) | |
| طلبات الهامش المتغير المتوقعة في كل سيناريو | |
| رفع البورصة للهوامش المبدئية في الأزمات (افتراض +50%) | |
| **الاحتياج النقدي الإجمالي لكل سيناريو** | |
| المصادر المتاحة: النقد الحر | |
| خطوط تمويل الهوامش المؤكدة من البنوك (Margin Financing Lines) | |
| خطوط القاعدة الإقراضية (الجزء المتاح) | |
| إمكانية تحويل التحوط إلى خيارات (تقليل الهوامش) | |
| بيع جزء من المخزون الفعلي/تسريع الشحن | |
| **الفجوة (إن وجدت)** | |
| الإجراءات لسد الفجوة | |
| المسؤول وجدول المراجعة | |

## ب11د.3 مثال

?> شركة متحوطة ببيع 1,500 عقد قمح MATIF (75,000 طن) بسعر 230 يورو.
?> - سيناريو +20%: حركة 46 يورو × 75,000 = 3.45 مليون يورو طلبات هامش متغير.
?> - رفع الهامش المبدئي من 12 إلى 18 يورو/طن: +450,000 يورو.
?> - الاحتياج ≈ 3.9 مليون يورو.
?> - المتاح: نقد 0.8 مليون، خط هامش بنكي 2.0 مليون، القاعدة الإقراضية (زيادة قيمة المخزون ترفع المتاح) 1.2 مليون ⇒ 4.0 مليون. الفجوة صفر تقريبًا، لكن السيناريو +30% يخلق فجوة ⇒ الإجراء: التفاوض على زيادة خط الهامش، أو تحويل جزء من التحوط إلى خيارات Put مشتراة.

## ب11د.4 أسئلة مراجعة

1) لماذا قد يحتاج المتحوط نقدًا كبيرًا رغم أن مركزه الاقتصادي متوازن؟
2) ما مصادر سد الفجوة النقدية؟
3) احسب الاحتياج في المثال لسيناريو +30%.
4) كيف يقلل التحول إلى الخيارات احتياجات الهامش؟
5) من يجب أن يملك خطة السيولة ويراجعها؟
