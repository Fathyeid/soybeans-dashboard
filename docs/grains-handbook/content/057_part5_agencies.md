# الفصل ظ40: اختيار شركات المعاينة والوكلاء والتعاقد معهم

## ظ40.1 معايير اختيار شركة المعاينة

| المعيار | الأسئلة |
|---|---|
| الاعتماد | هل هي معتمدة من GAFTA/FOSFA؟ هل مختبراتها معتمدة وفق ISO/IEC 17025؟ |
| الحضور المحلي | هل لها فريق دائم في ميناء التحميل/التفريغ؟ |
| الخبرة في السلعة | هل تعمل بانتظام في الحبوب/الزيوت؟ |
| السمعة | هل نتائجها مقبولة من البنوك والمشترين والجهات الرقابية في الوجهة؟ |
| الاستقلالية | هل لها مصالح مع أطراف أخرى في الصفقة؟ |
| سرعة التقارير | تقارير يومية وشهادات خلال 24–48 ساعة |
| التكلفة | الرسوم لكل طن أو لكل خدمة |
| التأمين | تغطية مسؤولية مهنية |

## ظ40.2 اتفاقية مستوى الخدمة (SLA) المقترحة

| البند | المحتوى |
|---|---|
| نطاق الخدمات | تفتيش العنابر، العينات، التحليل، مسح الغاطس، التبخير، الشهادات |
| المعايير | قواعد GAFTA 123/124/130 أو FOSFA، وطرق ISO المحددة |
| المهل | التقرير اليومي، الشهادات خلال X ساعة من انتهاء التحميل |
| العينات | العدد، الوزن، الحفظ (المدة والظروف)، التوزيع |
| التواصل | نقطة اتصال 24/7 أثناء العمليات |
| المسؤولية | حدود المسؤولية، التأمين |
| الرسوم | جدول الأسعار والمصاريف الإضافية |
| السرية | |

## ظ40.3 اختيار الوكيل البحري

- **الوكيل يمثل السفينة**، لكن المستأجر قد يرشحه (Charterers' Agents) في الموانئ التي يريد السيطرة على العمليات فيها.
- **حساب المصاريف التقديري (PDA)** قبل الوصول، و**النهائي (FDA)** بعد المغادرة؛ راجع الفروق وطالب بالإيصالات.
- **كشف الوقائع** يُعده الوكيل: دقته أساس حساب الغرامات.

## ظ40.4 أسئلة مراجعة

1) ما أهم معايير اختيار شركة المعاينة؟
2) لماذا يهم اعتماد المختبر وفق ISO/IEC 17025؟
3) ما بنود اتفاقية مستوى الخدمة؟
4) ما الفرق بين PDA وFDA؟
5) لماذا يرغب المستأجر في ترشيح الوكيل أحيانًا؟
