# الفصل ظ39: دراسة حالة — معصرة صويا مستوردة من الشراء إلى بيع المنتجات

## ظ39.1 الوضع

معصرة طاقتها 3,000 طن/يوم (حوالي 950,000 طن سنويًا بتشغيل 320 يومًا)، تستورد الصويا من البرازيل والولايات المتحدة والأرجنتين/باراغواي، وتبيع الكُسب لمصانع الأعلاف المحلية والزيت الخام للمصافي (أو تكرره داخليًا).

## ظ39.2 نموذج الربحية الشهري

| البند | لكل طن فول (دولار) |
|---|---|
| تكلفة الفول واصلًا (CFR 470 + تفريغ ونقل 12 + فاقد 2) | 484 |
| تكلفة العصر (طاقة، هكسان، عمالة، صيانة، تمويل) | 28 |
| **التكلفة الكلية** | **512** |
| إيراد الكُسب (0.78 × 470) | 366.6 |
| إيراد الزيت الخام (0.19 × 1,000) | 190 |
| إيراد القشور (0.03 × 120) | 3.6 |
| **الإيراد الكلي** | **560.2** |
| **الهامش** | **48.2** |

## ظ39.3 إدارة المخاطر

| المخاطرة | الإجراء |
|---|---|
| هامش العصر | تثبيت الهامش للأشهر القادمة عند مستويات مستهدفة بشراء الفول وبيع الكُسب والزيت في CBOT (10:11:9) |
| البيسيس المحلي للكُسب | عقود بيع محلية بأسعار مرتبطة بـ CBOT + علاوة محلية |
| بريميوم الفول | الشراء التدريجي، تنويع المناشئ حسب الموسم |
| العملة | تسعير الكُسب المحلي بالدولار أو مرتبطًا بسعر الصرف |
| السموم والسالمونيلا في الكُسب | مراقبة الجودة، تحميص كافٍ |
| التوقف | جدولة الصيانة في فترات الهامش الضعيف |

## ظ39.4 قرار تشغيلي: متى تخفض التشغيل؟

?> إذا انخفض هامش العصر المحلي (بعد كل التكاليف المتغيرة) تحت الصفر، فكل طن إضافي يُعصر يخسر. لكن المعصرة لها تكاليف ثابتة (رواتب، استهلاك، فوائد) تتحمل جزءًا منها حتى لو توقفت، وعقود بيع كُسب ملزمة لعملائها. القرار:
?> - هامش متغير > 0: الاستمرار (يغطي جزءًا من الثابت).
?> - هامش متغير < 0 لفترة قصيرة: الاستمرار بطاقة مخفضة لتلبية العقود، وجدولة الصيانة.
?> - هامش متغير < 0 لفترة طويلة: التوقف المؤقت والنظر في استيراد الكُسب مباشرة لتلبية العملاء.

## ظ39.5 أسئلة مراجعة

1) احسب الهامش إذا انخفض الكُسب إلى 440 والزيت إلى 950.
2) كيف تثبت المعصرة هامشها للأشهر القادمة؟
3) متى يكون التوقف المؤقت مبررًا؟
4) لماذا تربط المعصرة أسعار الكُسب المحلي بـ CBOT؟
5) ما مخاطر الجودة الخاصة بالكُسب المنتج محليًا؟
