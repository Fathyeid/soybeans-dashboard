# الفصل ظ58: عقود التخزين والاستئجار في الصوامع

## ظ58.1 متى تحتاج عقد تخزين؟

- عندما يخزن التاجر بضاعته في صوامع يملكها طرف آخر (مشغل ميناء، مطحنة، شركة تخزين).
- عندما يقدم مالك الصوامع خدمة تخزين للغير.
- عند تمويل المخزون (مع البنك ومدير الضمانات).

## ظ58.2 البنود الأساسية

| البند | المحتوى |
|---|---|
| الأطراف والموقع | المخزن، الصوامع المحددة |
| السلعة والكمية | مع الجودة عند الاستلام |
| الاستلام | طريقة الوزن والعينات وتحديد الجودة عند الدخول |
| الرسوم | رسوم الاستلام (Intake)، التخزين الشهري/اليومي، الإخراج (Outloading)، الخدمات الإضافية (تبخير، تنظيف، تجفيف) |
| الفاقد المسموح | نسبة فاقد طبيعي يتحملها المالك (مثلًا 0.25% لكل شهر أو مقطوعة) |
| المسؤولية | مسؤولية المخزن عن الفقد والتلف بسبب الإهمال، والحدود |
| التأمين | من يؤمن البضاعة (المالك أو المخزن) وضد ماذا |
| الخلط | هل تُخزن البضاعة منفصلة (Identity Preserved) أم مختلطة مع بضائع آخرين من نفس الدرجة (Commingled)؟ |
| الإفراج | بأوامر مكتوبة من المالك (أو البنك إذا كانت مرهونة) |
| الإيصالات | إصدار إيصالات تخزين ونوعها |
| الحق في الحبس | حق المخزن في حبس البضاعة لتحصيل رسومه |
| المدة والإنهاء | |
| النزاعات | القانون والتحكيم |

## ظ58.3 مثال تكلفة تخزين

?> 20,000 طن قمح، 4 أشهر: الاستلام 2.5 دولار/طن، التخزين 1.8 دولار/طن/شهر، الإخراج 2.5 دولار/طن، تبخير واحد 0.6 دولار/طن، فاقد 0.3% (من قيمة 260).
?> التكلفة = 2.5 + 7.2 + 2.5 + 0.6 + 0.78 = 13.58 دولار/طن ≈ 271,600 دولار.

## ظ58.4 أسئلة مراجعة

1) ما الفرق بين التخزين المنفصل والمختلط؟
2) لماذا يحتاج البنك أن تكون أوامر الإفراج منه؟
3) احسب تكلفة تخزين 6 أشهر في المثال.
4) ما الفاقد المسموح؟ ومن يتحمله؟
5) ما حق الحبس للمخزن؟
