# الفصل ظ33: قراءة اختبارات العجين — الألفيوجراف والفارينوجراف للتاجر

## ظ33.1 لماذا يحتاج التاجر فهم اختبارات العجين؟

المطاحن الكبيرة لا تشتري القمح بالبروتين فقط، بل بخصائص العجين التي تحدد جودة الخبز. المورد الذي يفهم هذه الاختبارات يستطيع مناقشة المطحنة، واقتراح المنشأ المناسب، وتجنب النزاعات.

## ظ33.2 الألفيوجراف (Alveograph — شوبان)

يقيس سلوك العجين عند نفخه كفقاعة حتى ينفجر، محاكيًا تمدد العجين بالغاز أثناء التخمر.

| القراءة | المعنى | القيم الشائعة |
|---|---|---|
| W (الطاقة) | قوة الدقيق الإجمالية (×10⁻⁴ جول) | 150–200 للخبز الأوروبي العادي؛ 200–300 للخبز القوي؛ أقل من 150 للبسكويت |
| P (الضغط/الصلابة) | مقاومة العجين للتشوه | |
| L (الطول/التمدد) | قابلية التمدد | |
| P/L (التوازن) | العلاقة بين الصلابة والتمدد | 0.5–1.0 للخبز الجيد؛ مرتفع جدًا = عجين صلب يصعب تشكيله؛ منخفض جدًا = عجين رخو |
| Ie (مؤشر المرونة) | | |

## ظ33.3 الفارينوجراف (Farinograph — برابندر)

يقيس مقاومة العجين للخلط مع الزمن عند إضافة الماء.

| القراءة | المعنى | القيم الشائعة لدقيق الخبز |
|---|---|---|
| امتصاص الماء (%) | كمية الماء للوصول لقوام محدد؛ أعلى = عجين أكثر من نفس الدقيق | 58–64% |
| زمن التطور (دقيقة) | الزمن للوصول للقوام الأقصى | 2–7 |
| الثبات (دقيقة) | مدة بقاء العجين في القوام الأقصى | 5–15 (أطول = أقوى) |
| درجة الضعف/الانهيار | الانخفاض بعد فترة | أقل = أفضل |

## ظ33.4 الإكستنسوجراف (Extensograph)

يقيس مقاومة العجين للمط ومدى تمدده بعد فترات راحة (45، 90، 135 دقيقة)، مفيد لقياس استجابة العجين للمحسنات ولأثر حشرة السونة (انهيار المقاومة مع الوقت).

## ظ33.5 قراءة نتائج القمح حسب المنشأ (اتجاهات عامة)

| المنشأ | الخصائص النمطية |
|---|---|
| الكندي CWRS | W مرتفع، ثبات طويل، امتصاص عالٍ — "قمح مُحسِّن" للخلطات |
| الأمريكي HRS/HRW | قوة جيدة إلى عالية |
| الروسي 12.5% | متوسط إلى جيد، مع تباين بين الشحنات؛ انتبه للسونة |
| الفرنسي 11.5% | W متوسط، P/L متوازن غالبًا؛ مناسب للخبز الفرنسي |
| الأسترالي APW | متوسط، لون أبيض، مناسب للنودلز والخبز المسطح |
| الأمريكي SRW | ضعيف — للبسكويت والكيك |

## ظ33.6 استخدام النتائج في التجارة

?> مطحنة تطلب "W لا يقل عن 220 وP/L بين 0.6 و1.2". إذا كان القمح المعروض روسيًا ببروتين 12.5% وW متوسط 190، يمكن اقتراح خلط 20–25% من قمح أعلى قوة (كندي أو روسي 13.5%) لرفع W للمستوى المطلوب، مع حساب التكلفة الإضافية مقابل شراء قمح أقوى بالكامل.

## ظ33.7 أسئلة مراجعة

1) ما الذي يقيسه W في الألفيوجراف؟
2) ماذا يعني P/L مرتفع جدًا؟
3) لماذا امتصاص الماء مهم اقتصاديًا للمطحنة والمخبز؟
4) كيف يكشف الإكستنسوجراف أثر حشرة السونة؟
5) كيف تقترح حلًا لمطحنة تطلب W أعلى من القمح المعروض؟
