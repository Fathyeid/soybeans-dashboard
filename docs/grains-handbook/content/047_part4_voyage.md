# الفصل ط: ورشة عمل — حساب الرحلة (Voyage Estimate) ودليل موانئ التحميل

## ط.1 لماذا يحتاج التاجر حساب الرحلة؟

حتى لو لم تكن مالك سفن، يجب أن تعرف كيف يحسب المالك النولون، لتعرف متى يكون العرض عادلًا، ومتى يمكنك التفاوض، ولتقدر النولون قبل أن تحصل على عروض فعلية عند تسعير صفقة CFR.

## ط.2 مكونات حساب الرحلة

| المكون | الوصف |
|---|---|
| المسافات | من موقع السفينة الحالي إلى ميناء التحميل (Ballast Leg)، ثم إلى ميناء التفريغ (Laden Leg) |
| السرعة والاستهلاك | سرعة السفينة فارغة ومحملة، واستهلاك الوقود في البحر وفي الميناء |
| أيام الموانئ | التحميل والتفريغ والانتظار |
| أسعار الوقود | VLSFO في البحر، MGO في الموانئ أحيانًا |
| رسوم الموانئ والقنوات | في الطرفين، والمضائق والقنوات |
| العمولات | العنوان + الوساطة |
| الأجرة اليومية المستهدفة | سعر السوق الزمني لهذه الفئة (TCE المستهدف) |
| تكاليف أخرى | تأمين إضافي (حرب، عمر)، تنظيف العنابر، مسح الغاطس، تبخير، أمن |

## ط.3 مثال كامل: سوبراماكس من البحر الأسود إلى الإسكندرية

### البيانات

| البند | القيمة |
|---|---|
| السفينة | سوبراماكس 57,000 DWT، تحمل 55,000 طن قمح |
| الموقع الحالي | مرمرة (تركيا)، فارغة |
| ميناء التحميل | نوفوروسيسك |
| ميناء التفريغ | الإسكندرية |
| المسافة مرمرة ← نوفوروسيسك | حوالي 580 ميلًا بحريًا (عبر البوسفور) |
| المسافة نوفوروسيسك ← الإسكندرية | حوالي 1,100 ميل بحري (عبر البوسفور والدردنيل) |
| السرعة | 12.5 عقدة فارغة، 12 عقدة محملة |
| الاستهلاك في البحر | 24 طن/يوم فارغة، 26 طن/يوم محملة |
| الاستهلاك في الميناء | 3 طن/يوم |
| سعر الوقود | 600 دولار/طن |
| التحميل | 10,000 طن/يوم + يوم للإجراءات |
| التفريغ | 5,000 طن/يوم + 2 يوم انتظار وإجراءات |
| رسوم ميناء التحميل | 70,000 دولار |
| رسوم ميناء التفريغ | 80,000 دولار |
| المرور في المضائق التركية (ذهابًا وإيابًا مع الإرشاد) | 30,000 دولار |
| أقساط حرب إضافية (البحر الأسود) | 40,000 دولار |
| العمولات | 5% (3.75% عنوان + 1.25% وساطة) |
| الأجرة اليومية المستهدفة (TCE) | 14,000 دولار/يوم |

### الحساب

| البند | الحساب | النتيجة |
|---|---|---|
| أيام الرحلة الفارغة | 580 ÷ (12.5 × 24) | 1.93 يوم |
| أيام الرحلة المحملة | 1,100 ÷ (12 × 24) | 3.82 يوم |
| أيام الانتظار في المضائق (تقدير) | | 1.0 يوم |
| أيام التحميل | 55,000 ÷ 10,000 + 1 | 6.5 يوم |
| أيام التفريغ | 55,000 ÷ 5,000 + 2 | 13.0 يوم |
| **إجمالي الأيام** | | **26.25 يوم** |
| وقود البحر | 1.93 × 24 + (3.82 + 1.0) × 26 | 171.6 طن |
| وقود الميناء | (6.5 + 13) × 3 | 58.5 طن |
| تكلفة الوقود | 230.1 × 600 | 138,060 دولار |
| رسوم الموانئ والمضائق والحرب | 70,000 + 80,000 + 30,000 + 40,000 | 220,000 دولار |
| **تكاليف الرحلة** | | **358,060 دولار** |
| الأجرة المستهدفة | 26.25 × 14,000 | 367,500 دولار |
| **الإيراد الصافي المطلوب** | 367,500 + 358,060 | 725,560 دولار |
| الإيراد الإجمالي (قبل العمولات 5%) | 725,560 ÷ 0.95 | 763,747 دولار |
| **النولون المطلوب** | 763,747 ÷ 55,000 | **13.89 دولار/طن** |

> لاحظ أن أيام التفريغ (13 يومًا) هي أكبر بند زمني. لو رفع المشتري معدل التفريغ إلى 8,000 طن/يوم، تنخفض الأيام بحوالي 4.1 يوم، فينخفض النولون المطلوب بحوالي (4.1 × (14,000 + 1,800)) ÷ 0.95 ÷ 55,000 ≈ 1.24 دولار/طن. معدل التفريغ له قيمة نقدية مباشرة في النولون.

## ط.4 حساسية النولون

| تغيير | الأثر التقريبي على النولون (دولار/طن) |
|---|---|
| +1,000 دولار/يوم في الأجرة السوقية | +0.50 |
| +50 دولار/طن في سعر الوقود | +0.22 |
| +1 يوم انتظار في التفريغ | +0.30 |
| +10,000 طن في حجم الشحنة (نفس السفينة إن أمكن) | −1.5 إلى −2 تقريبًا (توزيع التكاليف الثابتة) |

## ط.6 أسئلة مراجعة

1) احسب النولون المطلوب في المثال إذا كانت الأجرة المستهدفة 18,000 دولار/يوم.
2) لماذا يؤثر معدل التفريغ على النولون بهذا الشكل؟
3) ما أثر زيادة سعر الوقود 100 دولار/طن على النولون في المثال؟
4) لماذا قد تكون سفينة أكبر أرخص للطن رغم أن أجرتها أعلى؟
5) اذكر ثلاثة موانئ تحميل تتأثر بالطقس أو المياه وكيف.
