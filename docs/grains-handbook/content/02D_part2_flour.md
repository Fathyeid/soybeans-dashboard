# الفصل ظ16: تجارة الدقيق والمكرونة والمنتجات المصنعة من الحبوب

## ظ16.1 لماذا يهتم تاجر الحبوب بالدقيق؟

- بعض الدول تستورد الدقيق بدلًا من القمح (لنقص المطاحن أو لاعتبارات سعرية)، مثل دول في أفريقيا والشرق الأوسط وآسيا.
- دول أخرى تصدر الدقيق بكميات كبيرة (تركيا، كازاخستان، الإمارات، مصر، الاتحاد الأوروبي، الأرجنتين).
- التاجر الذي يفهم الدقيق يستطيع خدمة عملاء المطاحن بشكل أفضل، أو الدخول في تجارة الدقيق نفسها.

## ظ16.2 السوق العالمي للدقيق

| البعد | الملاحظات |
|---|---|
| حجم التجارة | 15–18 مليون طن مكافئ قمح تقريبًا |
| المصدرون الرئيسيون | تركيا (الأكبر غالبًا)، كازاخستان، الإمارات، أوزبكستان (مستورد)، الاتحاد الأوروبي، الأرجنتين، روسيا |
| المستوردون | العراق، اليمن، أفغانستان، دول آسيا الوسطى، الصومال، السودان، غرب ووسط أفريقيا، الفلبين، ليبيا، سوريا |
| التعبئة | أكياس 25 و50 كجم، أكياس كبيرة؛ يُشحن في حاويات أو سفن صغيرة (Breakbulk) |

## ظ16.3 مواصفات الدقيق

| العامل | الوصف | القيم النموذجية لدقيق الخبز |
|---|---|---|
| الرطوبة | | 14% حد أقصى |
| البروتين | | 10.5–12.5% |
| الرماد | مؤشر على الاستخلاص واللون | 0.55–0.70% |
| الغلوتين الرطب | | 26–30% |
| رقم السقوط | | 250–350 ثانية |
| الألفيوجراف W | | 180–280 |
| الإضافات | فيتامين C (حمض الأسكوربيك)، إنزيمات، تدعيم بالحديد وحمض الفوليك (إلزامي في دول كثيرة) | حسب التشريع |
| الصلاحية | | 6–12 شهرًا في ظروف تخزين جيدة |

## ظ16.4 اقتصاديات تصدير الدقيق

?> مثال: مطحنة تركية تستورد قمحًا روسيًا (CFR 255) بنظام السماح المؤقت وتصدر الدقيق للعراق.
?> - قمح لكل طن دقيق (استخلاص 75% تقريبًا): 1.333 طن × 255 = 340 دولار.
?> - تكلفة الطحن والتعبئة (أكياس 50 كجم): 45 دولار.
?> - إيراد النخالة (0.31 طن × 180): −56 دولار.
?> - التكلفة الصافية للطن دقيق = 329 دولار.
?> - النقل للعراق (بالشاحنات أو البحر): 30 دولار.
?> - سعر البيع CPT: 380 دولار ⇒ هامش حوالي 21 دولار/طن دقيق.

## ظ16.5 المكرونة والبرغل والسميد

- **المكرونة:** من قمح الدورم أساسًا (أو خلطات في بعض الأسواق). مصدّرون رئيسيون: إيطاليا، تركيا، مصر (نشاط تصديري للمكرونة نما في السنوات الأخيرة).
- **السميد:** من الدورم لصناعة المكرونة والكسكسي.
- **البرغل:** قمح مسلوق مجروش؛ تركيا مصدر رئيسي.

## ظ16.6 مخاطر تجارة الدقيق

| المخاطرة | الملاحظات |
|---|---|
| الصلاحية والتلف | الحشرات (خنفساء الدقيق)، الرطوبة، التزنخ |
| التشريعات | التدعيم الإلزامي، الوسم باللغة المحلية، التسجيل |
| المنافسة | هوامش ضيقة ومنافسة شديدة |
| اللوجستيات | التعبئة والحاويات وتأخيرات الموانئ في الوجهات الصعبة |
| الدفع | أسواق عالية المخاطر |

## ظ16.7 أسئلة مراجعة

1) لماذا تستورد بعض الدول الدقيق بدلًا من القمح؟
2) ما أهم مواصفات دقيق الخبز؟
3) احسب التكلفة الصافية للطن دقيق إذا كان القمح 270 CFR.
4) ما دور نظام السماح المؤقت في صناعة تصدير الدقيق؟
5) اذكر ثلاث مخاطر خاصة بتجارة الدقيق.
